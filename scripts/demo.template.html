bcrp

El Perú hoy

Último dato publicado.

Instantánea del {{UPDATED}}, obtenida con el propio bcrp. Cada indicador muestra su periodo y su fuente.

{{CARDS}}

Los datos mensuales se publican con semanas de rezago. Las variaciones se calculan con bcrp change.

Comandos

Un comando, un dato.

Funciona igual en la terminal, en scripts (JSON y CSV) y desde una IA.

Encontrar cualquier serie

El BCRP usa códigos como PD04638PD. Aquí buscas por nombre, en español o inglés.

$ bcrp search "tasa de referencia"
PD04722MM  monthly  Tasa de Referencia…
PD12301MD  daily    Tasa de Referencia…

Medir y resumir

Cuánto se movió algo, qué rango tuvo, o varias series lado a lado.

$ bcrp change fx --over ytd
Over ytd: 3.364 → 3.427
Change:   +0.064 (+1.89%)

$ bcrp stats inflation --last 12
$ bcrp compare inflation gdp --last 4

Convertir y avisar

Dólares y euros a soles con el tipo de cambio oficial, y alertas para tus scripts.

$ bcrp convert 100 usd
100.00 USD = {{CONVERT}} PEN

$ bcrp check fx --above 3.50 && notify

Exportar

JSON automático al encadenar comandos, y CSV para abrir en Excel.

$ bcrp get fx --from 2026-01 --csv > fx.csv
$ bcrp fx | jq .value

MCP

Conéctalo a tu IA.

Las IA no conocen el dólar de hoy. Con el servidor MCP tu asistente consulta la cifra oficial y responde con su fuente.

Claude Code

Una línea.

claude mcp add bcrp -- npx -y @lizethriveros/bcrp-cli mcp

Otros clientes MCP
